На первом прогоне обновления новая версия открылась только с третьего запуска. Причина — HTTP-кэш страницы в браузере. Поэтому service worker 0.8.1 качает файлы мимо HTTP-кэша (`cache:'reload'` при установке, `no-cache` для страницы). Следующие три прогона подряд — с первого запуска. Это важно для GitHub Pages, где страница кэшируется до ~10 минут.

**Производительность 0.8 → 0.8.1.** Маршрут: старт → место собраний → Пост 1 → Пост 2. Столбцы:

- «Худшая точка» — наибольшее падение в отдельной точке;
- «мс/кадр» — время логики и рендера без замедления.

Первый замер 0.8.1 в блэкаут дал −6…−11% FPS и +10…22% времени кадра. Добавились огни, отсветы с пятном на полу и пузыри реплик, а пиксельный текст рисовался заново каждый кадр. Что исправлено:
- пятна света всех ламп рисуются готовыми текстурами того же профиля, без градиента в каждом кадре;
- текст пузыря рисуется один раз.

FPS в headless квантуется по кадрам экрана (60, 30, 20, 15…), поэтому отдельные точки скачут сильнее средних. Время кадра без замедления точнее. Реальный FPS на iPhone не измерен.
