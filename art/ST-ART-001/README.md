Оригинал без изменений. Игра его **не загружает**. Контрольная сумма лежит в `SHA256SUMS`, её сверяет `tests/compat.test.js`.

Вариант В (решение Андрея 08.11.2026):

- правый павильон — рабочий вход: тёплый проём на 1-м этаже, над спуском в вестибюль (x 1650);
- торцевой дом — 3 подъезда без света;
- всё приведено к палитре «Дворов».

Подготовка: `python3 tools/art/prep_st.py` → `art/st/game/`, упаковка: `node tools/art/pack.mjs st` → `src/26-st-art.js`.
