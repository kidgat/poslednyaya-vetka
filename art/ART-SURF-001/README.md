# ART-SURF-001 — утверждённые рисунки поверхности (исходники)

Оригиналы без изменений: по ним сделана улица S1 «Дворы» (S1-ART). Игра эти файлы **не загружает**.
Контрольные суммы — `SHA256SUMS` (их сверяет `tests/compat.test.js`).

| Файл | Что | Куда в S1 |
|---|---|---|
| 01-sky.png | пасмурное небо | небо (параллакс 0,06) |
| 02-far-city.png | дальний город: трубы, кран, руины | дальний город (0,22) |
| 03-yard-long-house.png | длинный дом за площадкой | средний план (0,5) и двор на заднем плане (0,76) |
| 04-houses-street.png | две пятиэтажки, фонарь, «Жигули», завал, столб | пятиэтажки №1 и №2 (ячейки), предметы |
| 05-ground.png | асфальт, лужи, плиты, кирпичи, трава | земля, клочья травы, передний план |
| 06-garage-closed.png | гараж закрытый | гаражи (декорация) |
| 07-garage-open.png | гараж открытый | пока не используется |

Подготовка: `python3 tools/art/prep_s1.py` → `art/s1/game/`, упаковка: `node tools/art/pack.mjs` → `src/24-s1-art.js`.
