# ST-ART-002 — поверхность «Гагаринской» (панорама, редакция 2)

Уточнённый арт GPT для сцены SURF (ST-VIEW): та же композиция, что ST-ART-001
(левый завал · тёплый рабочий вход «ГАГАРИНСКАЯ» слева · длинная пятиэтажка с
заколоченными магазинами · проход «ДВОРЫ →» · перпендикулярный дом с муралом
Гагарина/СССР · разрушенный двухэтажный павильон справа · правый завал · машина,
мокрая площадь с отражениями), но чище свет, ярче отражения, аккуратнее надписи.

Размер 2172×724, координаты ориентиров совпадают с ST-ART-001 (тёплый вход ≈ x338,
проход «ДВОРЫ» ≈ x1385), поэтому двери сцены SURF не двигаются.

Исходник не менять (SHA256SUMS). Подготовка игрового фона: `python3 tools/art/prep_stview.py`
→ `art/stview/game/panorama.png`, упаковка `node tools/art/pack.mjs stview` → `src/29-stview-art.js`.
